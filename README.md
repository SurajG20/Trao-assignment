# Trao-assignment

AI Interview Prep Kit — backend first (Express + TypeScript + MongoDB, OpenRouter).

## Install and run

```bash
cd backend && npm install
cp ../.env.example ../.env
# fill OPENROUTER_API_KEY and SESSION_SECRET in .env
npm run dev
```

From the repo root:

```bash
npm test
npm run evaluate -- --input cases.json --output kits.json
```
